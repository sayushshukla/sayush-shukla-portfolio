# sayush-shukla-portfolio

My personal portfolio website showcasing my skills, projects, education, and experience in Full Stack Development and AI/ML.

## 🚀 Built With

- **React 19**
- **Vite**
- **Lucide Icons**
- **Canvas Confetti**
- **Modern Responsive CSS**

## 💻 Features

- Interactive Hero Section with quick stats
- Skills showcase across Programming, Frontend, Backend, Databases, and AI/ML
- Projects gallery with tags and demo links
- Education timeline & achievements
- Contact form & social media links
- Interactive resume preview modal

## 🛠️ Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/sayushshukla/sayush-shukla-portfolio.git
   cd sayush-shukla-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```
